# 联合总结的图谱查询取消

联合总结在每篇图谱查询结束后检查任务是否仍应继续，在跨文档图谱查询结束后也做同样的检查。后台任务复用进度回调核对 SQLite 中的取消标记、任务所有者和领取次数。查询正常返回、返回错误或抛出异常时均经过检查。已开始的图谱查询会等待驱动返回。

## 验证结果

- 三篇合成文档的第一篇图谱查询期间，向临时 SQLite 写入取消请求。修复前，两种执行方式均查询了三篇文档和共享图谱。修复后，均只查询第一篇，任务和消息正常进入取消状态，模型调用和保存引用数均为零。共享图谱查询期间收到取消时，也能在查询返回后停止。
- 项目虚拟环境通过 155 项后端测试，涵盖后台任务、所有权检查、普通问答及对比、图谱错误和两种执行方式。另运行八次真实任务与临时 SQLite 的对照检查，覆盖图谱返回错误或抛出异常的情形。
