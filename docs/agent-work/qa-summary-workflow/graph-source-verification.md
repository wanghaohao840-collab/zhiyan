# 联合总结图谱引用展示与复制

新保存的逐篇图谱来源会附上同一文档的文件名、实体名称或关系证据，并生成包含稳定编号和文件名的可复制引用。关系证据最多展示模型实际收到的前 240 个字符。没有证据文本的关系会显示关系类型和提示。共享图谱仍按原规则保存到贡献文档。旧记录沿用已经保存的字段。

## 验证结果

- Windows 项目环境通过 159 项定向测试。两种执行方式都用实际后台任务写入临时 SQLite，覆盖了实体、长关系证据和无证据关系，以及稳定引用编号和所属文档。
- Chromium 在 1440×1024 和 390×844 各通过一项浏览器测试。打开摘要引用后，卡片显示文档名、图谱名称和编号。点击复制，剪贴板内容与对应卡片一致。
- Linux Python 3.11 容器以只读方式运行当前工作树代码，通过 206 项定向测试。容器使用已有依赖，禁用了外部网络。
