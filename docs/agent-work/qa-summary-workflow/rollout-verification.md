# 多文档联合总结实测与交付

## 对照实测

在独立的运行目录、应用账号、SQLite 和 JSON 索引上，通过产品 API 导入三份 RFC 原版 PDF 的分页摘录。两条路径使用同一个真实模型测试账户和同一问题。原始页按打印页码记录，应用内页码以导入后的摘录顺序为准。

- RFC 9110 原页 72、73。核对安全方法与幂等性的区别，以及 PUT、DELETE 的归类。[RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.pdf)
- RFC 9111 原页 11–13。核对共享缓存的 s-maxage 优先，随后是 max-age，再用 Expires。[RFC 9111](https://www.rfc-editor.org/rfc/rfc9111.pdf)
- RFC 9112 原页 18、19。核对两种分帧头并存时由 Transfer-Encoding 决定消息分帧。[RFC 9112](https://www.rfc-editor.org/rfc/rfc9112.pdf)

问题要求比较三份摘录，说明哪些 HTTP 方法是安全的、幂等性有何区别、max-age 和 Expires 谁优先，以及 Transfer-Encoding 与 Content-Length 同时出现时谁优先。每项事实都要附来源编号。

| 路径 | 场景 | 任务结果 | 含轮询总耗时 | 模型调用 |
| --- | --- | --- | ---: | ---: |
| 顺序 | 冷缓存 | 完成 | 18.78 秒 | 4 |
| 顺序 | 三篇单篇摘要已缓存 | 完成 | 7.08 秒 | 1 |
| LangGraph | 冷缓存 | 完成 | 36.08 秒 | 4 |
| LangGraph | 三篇单篇摘要已缓存 | 完成 | 10.05 秒 | 1 |
| LangGraph | 一篇取样返回空，其余命中缓存 | 完成并列出缺失项 | 6.44 秒 | 1 |
| LangGraph | 汇总模型调用已经开始时取消 | 取消，未写回答案或来源 | 9.73 秒 | 1 |

最终对照使用 DeepSeek Chat。两条路径的冷、暖答案均包含三项规则，出现的来源编号均能在已持久化的来源中查到。对应原文支持页为 RFC 9110 第 73 页、RFC 9111 第 13 页，以及 RFC 9112 第 18 页。初次测试用本地默认的 DeepSeek Reasoner，在当前 1024 token 输出上限下耗尽了预算，模型未给出可用摘要。之后使用同账户的 DeepSeek Chat，以同一测试模型比较两条路径。一次单独重测遇到读取任务状态 HTTP 500，后续降低轮询频率重新执行，同一错误未再出现。样本量只足以验证本例，耗时差不用于推断线上性能。

实测暴露的取样漏项已修复。本地摘要先覆盖不同页，再用剩余位置补同页后续片段。上下文容量不足时，用已有词面匹配优先保留与问题相关的证据。联合总结提示减少重复内容，输出预算仍为 1024 token。

## 续租与取消

原版本已复现慢调用期间无续租，以及等到 SQLite 写锁时租约实际已经到期仍接受结果。修订后任务在生成期间定期续租，保留步骤进度。每次任务领取都有独立的领取次数，更新必须匹配当前所有者和次数。取得写锁后重新读取时间，旧任务的迟到结果无法覆盖新任务的结果。关闭请求若早于提交事务取得写锁，也会阻止最终写入。已经送达模型服务的请求可能在取消后仍运行到结束。

GPT-6.2 Astra High 独立终审通过。35 项聚焦测试通过，跨日期偏移和微秒边界另验证 45 组，并在实际 Python 3.10.11 中检查完成、失败与 SQLite 锁异常分类。

## 小范围开启与回退

2026-11-24 在只绑定本机回环地址的独立 HTTP 服务上开启 LangGraph。服务使用专用测试账号、独立 SQLite 和全新 Qdrant 容器，复用上述三个公开文档和 DeepSeek Chat 测试配置。三份文档和三次联合总结均完成，生成答复中的引用编号均对应到已保存的来源。

| 场景 | 含轮询总耗时 | 模型调用 | 验证结果 |
| --- | ---: | ---: | --- |
| LangGraph 冷缓存 | 18.31 秒 | 4 | 四个阶段可见，三篇文档有可用来源 |
| LangGraph 暖缓存 | 5.94 秒 | 1 | 三篇单篇摘要命中缓存 |
| 清除开关并重启 | 11.09 秒 | 4 | 新任务走顺序流程，旧答案与来源逐项一致 |

三次真实模型调用组均无传输失败。核对了幂等性、新鲜度优先级和报文分帧优先级。Qdrant 试运行有文档上下文裁剪，模型端的最终输出正常结束；已核对原题所需三项证据仍可用。试运行服务随回退验证结束停止，专用 Qdrant 容器由本次任务清理。

集成目标为试点的直接父分支 'codex/next-improvements'。相对于该分支起点 'f02a660'，交付范围为联合总结试点、续租、证据取样和验收记录。实际生产容器配置仍由原部署工作流管理，本轮未切换生产镜像或修改生产数据。该线上实例的环境开关不用于区分账号，本轮只在隔离实例实际开启。

最终提交内容在 Windows Python 3.12 通过 125 项相关回归测试。
