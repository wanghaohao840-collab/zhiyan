# 联合总结取消后的传输重试

后台联合总结使用内置模型客户端时，每次传输重试前都会重新核对任务状态。任务在退避等待期间被取消，或已失去租约，客户端会在发出下一次请求前停止。等待期间已发出的请求由模型服务自行结束。

## 验证结果

- 项目虚拟环境通过 175 项定向回归。覆盖了自定义客户端继承摘要入口、重写传输方法的兼容情况。
- 在第一次最终汇总请求内写入 SQLite 取消标记，再触发连接错误。修复前，顺序执行共发出三次请求，LangGraph 发出一次。两种方式最终都取消任务。
- 新回归在两种执行方式下分别验证逐篇和最终汇总。首次请求后触发取消，传输层未再发出重试，任务和消息都进入取消状态，答案和来源为空。
- 模型传输测试验证任务仍有效时会正常重试，内部检查函数不会进入模型服务的请求参数。流式与普通模型调用也通过现有回归。
