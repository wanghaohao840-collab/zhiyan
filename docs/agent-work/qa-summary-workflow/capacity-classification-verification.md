# 联合总结容量错误识别

正常摘要可以包含“上下文长度”“context window”或“token limit”等表述。容量不足仍通过本地预算拒绝、供应商明确的 HTTP 400 容量错误，或旧接口返回的明确失败标记识别。模型输出达到上限时，继续按摘要不完整处理。

## 验证结果

- 项目虚拟环境通过 187 项定向回归，包含模型传输、后台任务、存储和多文档工具。
- 顺序执行和 LangGraph 均以两份合成文档运行实际后台任务。逐篇摘要中的相关表述进入最终汇总，正常回答与来源写入 SQLite。测试覆盖旧文本接口和带结束状态的模型接口。
- 含容量原因的 HTTP 400 和旧接口失败文本仍保存为容量不足。不相关的 HTTP 400 和旧接口错误按各自原有的失败状态保存。失败消息没有正文和来源，日志没有供应商错误详情。
