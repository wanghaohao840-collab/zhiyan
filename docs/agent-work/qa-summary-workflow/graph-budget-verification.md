# 联合总结图谱容量与引用验收

逐篇摘要和最终汇总按各自的输入容量纳入完整图谱条目。被裁掉的逐篇条目不会进入汇总的允许引用列表。被裁掉的共享条目不会进入最终模型的资料。回答脚注和应用来源只列出已纳入的条目。仅能容下图谱标题时，提示词省略这个空章节。已纳入的条目继续使用原引用编号。

逐篇摘要的进程内缓存增加有效输入容量。相同容量下可继续复用摘要和来源，容量改变时重新计算，避免沿用另一容量下的引用。

## 验证结果

- 两种执行方式均复现了修复前的问题。用合成图谱验证逐篇证据超长、共享证据部分纳入、问题文字含同一引用编号、无图谱条目入模、同容量缓存命中和容量改变后重新计算。测试走了真实 `RagQaAnswerEngine` 到应用引用转换。
- 项目 Python 环境的多文档工具、数据后端契约、回答转换、任务执行和 Neo4j 存储测试通过 122 项。
