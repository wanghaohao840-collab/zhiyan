# 联合总结模型调用前的任务检查

后台联合总结在发起逐篇模型调用前，从 SQLite 读取当前领取状态。任务已取消、租约已到期，或已被重新领取时，旧任务会停止。读取连接在检查结束后关闭。读取不会续租或更新进度，缓存命中时无需发起模型请求。

数据库暂时被锁时，整项任务按已有规则重试。其他数据库读取错误使整项任务失败，即使已有部分文档生成了摘要。任务日志以固定原因记录检查失败。检查通过和请求发出之间仍有时间间隔。在这期间收到的取消可能赶不上当次请求，数据库仍会在保存时复核任务状态。

## 验证结果

- 项目虚拟环境通过 164 项定向回归，覆盖任务存储、后台执行、回答转换和多文档工具。
- 在第一篇文档取样期间提交取消，或让另一轮领取接手同一任务。顺序执行和 LangGraph 均在模型调用前停止，未写入旧答案。相同执行者重新领取时，领取次数也能区分新旧任务。
- 模拟并发逐篇生成时，一篇成功后另一篇查库出错。临时锁将整项任务重新排队，其他错误将任务及消息标为失败。两种情况都没有发出最终汇总请求或保存部分答案。
