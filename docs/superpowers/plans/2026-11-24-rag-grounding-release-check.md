# 单次证据校验上线前验收

基线 3855909。冻结一组独立的中英文测试题，使用现有 BGE-M3 和聊天模型，在隔离索引中以实际应用问答适配器的默认向量检索参数比较两种证据校验策略。观察每题答案、干净拒答、原文和页码回查、附带背景引用及问答耗时。线上数据和配置保持现状。

验收要求包括来源全部回查成功、零范围越界、单次组零问答错误、可答准确率与干净拒答率不低于同轮双次组、所有应答事实都带对应证据。直接指向标准证据的引用占比至少 95%。以同轮完整问答 P95 是否下降作为时延检查。若未通过，逐题判断问题来自候选召回、生成还是评分，并保留初测和复测证据。

首轮观察到明确说明无答案时仍附引用。复测加验全部缺证据题无引用拒答，保留首轮结果。两组统一采用新的生成上限，比较仅使用同轮数字。
