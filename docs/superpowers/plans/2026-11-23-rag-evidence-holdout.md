# RAG 盲测与证据校验实施计划

基线为 09b47cb。线上 SiliconFlow BGE-M3 的 402 已复现，服务端错误码 30001 表示余额不足。用户处理账户问题后，部署配置探针和运行容器均重新返回 1024 维向量。隔离评测使用恢复后的线上模型和临时索引。

1. 锁定独立中英文题集，标注每项事实的证据位置。覆盖近似版本、改写、多证据、部分证据、文档范围。先用线上 BGE-M3 比较向量、混合、现有相关性重排的前五命中、证据齐全率、排名和延迟。
2. 单独在问答链路增加 opt-in 的证据模式。第一步让模型逐项选出能回答问题的确切原文并给出证据不足判定。第二步从所选原文生成逐条带引用的结论。校验引用属于已选上下文、引文逐字存在、结论中的数值和标识符有原文复核依据。只回传实际引用的片段。模型输出格式错误时返回错误，证据确实不足时返回简洁拒答。
3. 固定题集、向量模型和生成设置，与上一轮问答方式比较。分别记录错误作答、可答题误拒、关键事实引用覆盖及支撑、调用故障与完整问答延迟。`tests/evals`、问答工具和应用适配器回归通过后，仅有新重排预期能解决的候选池错排时才试额外重排器。
