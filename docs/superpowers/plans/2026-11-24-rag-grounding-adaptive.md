# 多项问答证据校验与输出预算

基线 377fb29。添加可选 adaptive 策略。含多个明确问项的普通问答使用已有双次校验，其他问题沿用单次校验。依据问题文本决定策略，保留原有文档过滤与逐字引文检查。在实际应用适配器接入可选输出上限，传到调用模型的参数，同步预留上下文空间，普通问答的其余模式沿用原值。

在合成题集上比较 adaptive 和双次校验。使用相同应用适配器、向量检索、模型和输出上限。候选需 100% 答对可答题、干净拒答缺证据题、全部标注事实带直接来源、无越界或生成错误，且完整问答 P95 低于基准。如果基准有调用错误，保留证据并报告延迟比较受影响。复测上一轮漏答题并单列。保持生产配置由既有部署流程控制。
