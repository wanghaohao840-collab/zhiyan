## Death, pause and fault distinction

Separate genuine terminal-death tests from surviving-process suspension. A dead PID cannot be resumed. API/Worker death uses verified owned process termination plus wait/actualexit, then a separately attested replacement PID. Stale Worker uses a test-only bounded child barrier at an exact operation boundary while the process remains alive; it later resumes the same original tuple and must be rejected by real authority. Label this controlled operation pause, not an OS-wide suspension. Concurrent heartbeat must not secretly extend the paused attempt: pause it at a separate verified boundary or place the claim barrier before the heartbeat starts. Confirm both original task/user expiries with PostgreSQL clock before replacement recovery. Every barrier has parent nonce/case/stage identity, finite arrival/release deadlines, actual hit evidence and finally release/owned-process exit; no arbitrary sleeps establish causal arrival.
